# 🛒 E-Commerce Sales Data Analysis Dashboard

## 📌 Project Overview

This project analyzes e-commerce sales data using Python, SQL and
Streamlit. The project provides an interactive dashboard to understand
sales performance, customer behavior, product performance and regional
sales trends.

## 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing products
- Analyze sales by category
- Analyze sales by region
- Understand customer segments
- Analyze shipping modes
- Analyze monthly sales trends
- Provide interactive filters
- Generate business insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- SQL
- MySQL
- Streamlit
- Matplotlib
- Seaborn
- Excel
- Jupyter Notebook

## 📊 Dashboard Features

- Total Sales
- Total Orders
- Total Customers
- Total Products
- Category-wise Sales
- Region-wise Sales
- Top 10 Products
- Monthly Sales Trend
- Customer Analysis
- Segment Analysis
- Ship Mode Analysis
- State-wise Sales
- City-wise Sales
- Interactive Filters
- CSV Download

## 🚀 How to Run

Install required libraries:

pip install streamlit pandas numpy matplotlib seaborn mysql-connector-python

Run the dashboard:

streamlit run app.py

## 📌 Conclusion

The dashboard provides an interactive way to analyze e-commerce sales
data and identify important sales, customer, product and regional trends.
